# Nino's EnglishLab

### NO EXCUSES.

**Nino's EnglishLab** es una plataforma web interactiva de aprendizaje de inglés, inspirada visualmente en Nino Nakano, personaje del anime *The Quintessential Quintuplets*.

El proyecto busca ofrecer una experiencia de aprendizaje dinámica, combinando ejercicios interactivos, elementos de gamificación y, en futuras versiones, funcionalidades impulsadas por inteligencia artificial.

Su diseño utiliza una estética retro inspirada en los videojuegos, con elementos pixel art, animaciones y una interfaz personalizada.

> **Estado del proyecto:** En desarrollo. Actualmente se está trabajando en las funcionalidades del frontend.

## Funcionalidades

### Implementadas

- Interfaz web desarrollada con HTML, CSS y JavaScript.
- Diseño visual personalizado con temática retro y pixel art.
- Navegación entre las principales secciones de aprendizaje.
- Módulo de vocabulario con ejercicios interactivos.
- Validación de respuestas y retroalimentación visual.
- Sistema básico de puntuación, experiencia (XP) y rachas durante las sesiones.

### En desarrollo y próximas implementaciones

- Módulos interactivos de Listening y Grammar.
- Organización de ejercicios por niveles de dificultad.
- Reproducción de audio y ejercicios de comprensión auditiva.
- Persistencia del progreso de aprendizaje.
- Sistema de usuarios y autenticación.
- Integración con una API externa de inteligencia artificial para generar ejercicios y apoyar el aprendizaje.
- Implementación de backend, base de datos y medidas de seguridad.
- Mejoras de accesibilidad y adaptación a diferentes dispositivos.

## Tecnologías

### Actualmente utilizadas

- **HTML5:** estructura de las páginas.
- **CSS3:** diseño, estilos, animaciones y elementos visuales.
- **JavaScript:** lógica de interacción, ejercicios y actualización dinámica de la interfaz.

### Tecnologías previstas

- **React:** desarrollo y organización del frontend.
- **Python y FastAPI:** backend y construcción de API REST.
- **PostgreSQL:** almacenamiento de usuarios, resultados y progreso.
- **API de IA externa:** incorporación de funcionalidades inteligentes sin necesidad de entrenar un modelo propio.

La arquitectura y las tecnologías previstas podrán ajustarse conforme avance el desarrollo.

## Objetivos del proyecto

EnglishLab nace como un proyecto personal de aprendizaje y portafolio, con el propósito de:

- Fortalecer conocimientos de JavaScript y desarrollo frontend.
- Aplicar Python y FastAPI en una aplicación web real.
- Aprender integración de APIs REST y bases de datos.
- Implementar buenas prácticas de desarrollo y seguridad.
- Explorar la integración de servicios de inteligencia artificial.
- Construir una aplicación funcional que pueda evolucionar progresivamente.

## Estado actual

El desarrollo se encuentra enfocado en el frontend y en la implementación progresiva de las funcionalidades interactivas.

El módulo de Vocabulary ya cuenta con lógica de ejercicios en JavaScript. Los demás módulos y la infraestructura backend se incorporarán en futuras etapas.
